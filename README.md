# NinnnUtils
Ninnn Utils aims to be a all in one bot !

This bot has been made using the discord.py library !
the bot is versatile and is usable anywhere! (users and servers !!)

This bot does:
- basic fun and useful utility commands
- commands for server admins and automod
- An economy and Leveling system
- Minigames (Economy minigames, Counter)
- Welcome and goodbye messages with banners

## Usage
###  Installation

Run these commands to install the deps in a few seconds

```shell
git clone https://github.com/ImNinnn/NinnnUtils
cd NinnnUtils
pip install -r requirements.txt
```

### Configuration
Open .env up for editing, we'll configure the bot here,

#### Fields

| Argument              | Description                                                                                                       | Example                         |
|-----------------------|-------------------------------------------------------------------------------------------------------------------|---------------------------------|
| DISCORD_TOKEN         | Bot token (bot only, you can't run selfbots)                                                                      | MTUwMDc5ODUwMjczNTcwODI4MQ==... (turt how do you have my token ?) |
| BOT_VERSION           | The version the bot will show                                                                                     | S.1.1                           |
| BOT_VERSION_ALTERNATE | the single word that describes the version                                                                        | Split                           |
| ACTIVITY              | The activity that displays on the bot's profile (playing/watching)                                                | [none, idk what is the example] |
| SHARD_COUNT           | Sharding is required when your bot reaches 1500 servers or more, this specifies how many shards the bot will have | 10                              |
| PREFIX                | Prefix for owner/legacy commands                                                                                  | n!                              |
| COG_NAMES             | List of all the cogs the bot should load (from cogs/)                                                             | economy,fun,utils               |
